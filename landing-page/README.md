# InputBridge Landing Page

Static landing page for InputBridge downloads.

## Deploy

Upload the contents of this folder to any static host (GitHub Pages, Netlify, Vercel static, Cloudflare Pages, or any web server).

Required files:
- `index.html`
- `downloads/InputBridge-Windows.zip`
- `downloads/InputBridge-release.apk`

## Local preview

Open `index.html` in a browser, or serve the folder:

```powershell
python -m http.server 8080
```

Then visit `http://localhost:8080`.
