Control your Android phone
from Windows.

InputBridge routes keyboard and mouse input from Windows to Android over a trusted local network. Pair with QR, switch mode, and use a touch pointer when your phone is docked or out of reach.

$ inputbridge connect --qr --mode phone --network local
download windows.zip download android.apk

NOTE: connection != control. After pairing, press Switch to Phone on Windows to route input.

features

What is implemented in the current Windows desktop app and Android companion app.

windows app

desktop
  • QR pairing: Windows shows a QR with local host, port, and one-time token; no manual IP/code flow.
  • One primary action: Switch to Phone / Return to Laptop, with clear connected-but-local status.
  • Routing modes: Both, Keyboard only, Mouse only, Pause, and Emergency return.
  • Hotkeys: Shift+CapsLock toggle, CapsLock return in Phone mode, Ctrl+Alt+F12 emergency.
  • Diagnostics: connection, capabilities, pointer rate, queue/latency counters, and status logs.
  • Settings: device name, startup/default mode, scroll, button mapping, pointer rate, and appearance.

android app

companion
  • QR scan connect: scans Windows QR and connects as TCP client on the trusted local network.
  • Touch Pointer: Accessibility-based cursor overlay for tap, move, scroll, and button actions.
  • InputBridge IME: keyboard/text input path when InputBridge keyboard is selected.
  • Setup checklist: pairing, Accessibility, keyboard, and overlay status with direct actions.
  • Appearance & calibration: cursor shape/size/colors, preview, and calibration screen.
  • Safety: local return hotkeys, watchdog fail-safe, and AES-256-GCM post-pairing messages.

setup

Normal first run: install, pair, grant Android permissions, then activate Phone mode on Windows.

[01]

install

Run InputBridge.exe on Windows. Install the APK on Android and allow the install source if prompted.

[02]

pair + permissions

Scan the Windows QR from Android. Enable Accessibility for touch/cursor control and select InputBridge keyboard for typing.

[03]

switch to phone

Press Switch to Phone or Shift+CapsLock. Emergency return: Ctrl+Alt+F12.

notes

  • Connected is not active control. After pairing, input stays on laptop until you switch to Phone mode.
  • Emergency return. Ctrl+Alt+F12 returns control to Windows. In Phone mode, CapsLock also returns to Laptop.
  • Permissions. Accessibility is required for touch/cursor control. InputBridge IME is required for text input. Some devices need Display over other apps for the cursor overlay.
  • Trusted network only. Pairing is HMAC-signed and post-pairing traffic is AES-256-GCM encrypted; use on a network you control.
  • Evaluation signing. The release APK uses a self-signed evaluation certificate, not a production Play Store key.
